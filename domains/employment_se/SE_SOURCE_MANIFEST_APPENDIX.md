# SE Source Manifest Appendix

Migrationsverket's public Lifos site publishes legal guidance pages, including "Rättsligt ställningstagande" entries with visible "Läs dokumentet" links to PDFs. The pages checked in this pass are publicly accessible HTML/PDF content, but I did not verify a separate bulk/open-data API or a dedicated reuse-terms page, so bulk reuse should stay assessment-only until a dedicated terms review is done.

Migrationsöverdomstolen access runs through Domstol.se. The official court page identifies Kammarrätten i Stockholm as Migrationsöverdomstolen and points users to the "Sök rättspraxis" service, which includes guiding decisions from 2017 and references back to 2007, with search/filter and RSS access. That is a realistic official access route for case-law assessment; I did not bulk-fetch any decisions in this phase.
