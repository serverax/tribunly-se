CLIENT ARCHITECTURE DECISIONS
═══════════════════════════════════════════════════════════════════════════════

Static HTML served by FastAPI (not Next.js) chosen for Phase 3A MVP:
  - Zero new runtime deps (no Node.js in container)
  - No separate frontend service to orchestrate or debug
  - Full pipeline reachable from TestClient (no cross-origin issues in tests)
  - Sufficient for self-represented claimant use case at this stage

Assessment result is passed between pages via sessionStorage (not URL params
or a back-end session store). This keeps no fact data on the server beyond
the audit log written by the governance layer.
