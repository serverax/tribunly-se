═══════════════════════════════════════════════════════════════════════════════
TIMELINE (backend/engine/timeline.py)
═══════════════════════════════════════════════════════════════════════════════

build_timeline() generates events from:
  - case.key_dates (EDT, start, ACAS, deadline) → source=system_generated
  - ET deadline → source=rules_engine (authoritative backend value only)
  - Uploads → document_uploaded events
  - Generated docs → document_generated events
  - Handoff leads → handoff_triggered event
  - Confirmed/corrected extracted facts ONLY → source=confirmed_extraction
  - Manual DB events → source=user_entered (from case_timeline_events table)

GUARDRAILS:
  - Dates never invented; missing_date=True + warning when absent
  - Unconfirmed and rejected extracted facts excluded (get_confirmed_facts())
  - ET deadline always uses backend-authoritative rules_engine source
  - Timeline notes "not legal advice" and does not imply platform manages litigation

═══════════════════════════════════════════════════════════════════════════════
ESCALATION (backend/engine/timeline.py — compute_escalation())
═══════════════════════════════════════════════════════════════════════════════

States (priority order):
  1. solicitor_recommended  — seek_solicitor or (insufficient + low strength)
  2. handoff_started        — handoff lead exists for this case
  3. urgent_deadline        — deadline expired, within 7 or within 14 days
  4. needs_review           — insufficient_grounding or strength=low
  5. watch                  — deadline within 30 days
  6. none                   — no escalation needed

Returns: state, state_label, triggered_states, urgency, days_remaining,
         next_action, escalation_note.

GUARDRAIL: Never claims a solicitor has accepted the case.
GUARDRAIL: Purely deterministic — no model involvement.
GUARDRAIL: next_action text never implies platform manages litigation.

  document_generated | handoff_triggered | custom_user_event

Valid sources (4):
  user_entered | rules_engine | confirmed_extraction | system_generated

source='rules_engine' is reserved — users cannot set it via POST endpoint.

ENDPOINTS
═══════════════════════════════════════════════════════════════════════════════

GET   /cases/{id}/timeline                   — full timeline (auto + DB)
POST  /cases/{id}/timeline/events            — add manual event
PATCH /cases/{id}/timeline/events/{event_id} — update event title/date/status
GET   /cases/{id}/escalation[?as_of=DATE]    — escalation state

as_of param on escalation: allows deterministic testing with fixed reference date.
