2. KEY-MANAGEMENT READINESS
═══════════════════════════════════════════════════════════════════════════════

New module: backend/engine/kms.py

  env (default): ENCRYPTION_KEY env var — NOT production-grade
  kms_stub:      KMS interface exists; NOT connected to real HSM; acceptable for
                 production-readiness flag but Phase 7 implementation required

GUARDRAIL: env mode IS a production blocker.
GUARDRAIL: kms_stub hsm_connected=False — never claims real KMS.
